## Development

When starting the dev server, use background mode:

```bash
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Token Optimization Rules

- Minimize code length. Provide only requested changes to save maximum token credits.
- Never write extensive unchanged file contents or repetitive boilerplate code.
- Strictly double-check code syntax and verify imports before applying changes to prevent server breakages.

# UI & Copywriting Standard

- **Uncluttered Layout**: Keep the interface clean, spacious, and well-organized. Avoid overcrowding cards or components.
- **Concise Microcopy**: Use short, direct, and intuitive text (1–3 words for buttons, headers, and status badges). Avoid long sentences or formal fluff.
- **Clarity & Simplicity**: Ensure all labels and status indicators are self-explanatory, user-friendly, and effortless to understand at a glance.
- **Minimalist Aesthetic**: Use subtle borders, clean card containers, and generous padding to maintain a polished, modern look.
